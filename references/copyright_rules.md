# 版权与安全规则（copyright_rules.md）

本文件规定使用本技能处理小说文本时应尽的版权与安全义务。

## 使用前确认

要求用户确认文本属于以下**至少一种**情况：

- 用户原创
- 用户拥有版权
- 已获得作者或权利人授权
- 已进入公版领域
- 合法的私人研究用途

若用户无法确认，或明确用于无授权侵权发布，应拒绝处理。

## 义务要求

技能必须：

- 保留原文来源信息（记录在 `source/import_info.json`）。
- 默认在本地项目中处理，不主动公开或发布文本。
- 不主动上传第三方模型（除非用户明确配置）。
- 不将模型推断伪装成「原作者计划」。
- 不声称续写代表原作者。
- 避免无必要地复制大段原文（写入时只引用必要片段）。
- 导出时提示这是 **AI 辅助创作结果**。

## 项目元数据

`project.json` 的 `source_type` 记录权利类型：

```
user_owned | licensed | public_domain | research | ai_generated
```

## 触发拒绝

以下情况不调用完整技能或拒绝处理：

- 要求高度模仿某位**在世**作者并用于冒充。
- 明确使用无权使用的文本并用于侵权发布。
- 无前文却要求完全独立创作。
