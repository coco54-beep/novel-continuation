# 文风规则（style_rules.md）

本文件规定如何分析、还原与锁定续写的文风。

## 文风分析必须覆盖两类特征

### A. 抽象特征（可量化 / 可概括）

- 叙事人称（第一/第三人称）
- 视角范围（限知/全知、视角人物）
- 平均句长、长短句分布
- 对话比例、心理描写比例、环境描写比例、动作密度
- 比喻密度、感官描写偏好
- 转场方式、章末钩子、节奏、克制程度、诗性程度、口语化程度

### B. 具体抓手特征（决定「像不像」的关键，易被跳过）

这是续写最能体现「原味」的部分，**必须**单独提取：

- **文化 / 亚文化梗密度**：间接引用的游戏、动漫、电影、小说、综艺、网络文化的**具体符号**。例如《黑客帝国》的 Neo、星际争霸的「母巢/大和炮/机枪兵」、日漫《X》的「白金之星」、电影《Wall-E》的 Eve。
  要点：续写时应**沿用原文已有的文化符号体系**（同样的游戏、同样的动漫），而不是自创别的比喻。
- **生活细节质感**：具体到**品牌、绰号、道具、生活习惯**的实感。例如「高仿万宝龙表」「N96 手机」「泽太子」绰号、「寂寞的贪吃蛇」笔名、用红点（IBM 红帽）打星际争霸、采蒲公英、蹭报刊亭看杂志。
  要点：续写时应**延续原文的人物道具/绰号/习惯**，而非用通用词汇带过。
- **悲喜突变节奏**：情绪在极短篇幅内大起大落的切换方式。原文常在几行内从「被全班嘲笑」跳到「光芒压过所有人」，用荒诞对冲悲情。
  要点：续写应保留这种「上一秒憋屈、下一秒爆发」的节拍，而非线性递进。
- **角色口头禅 / 固定句法**：某个角色反复出现的惯用语、对白腔调、骂人/自嘲方式。

分析结果保存为 `analysis/style_profile.json`（全书风格指纹），其中**必须**包含 `cultural_references`（文化符号清单）、`material_details`（质感细节清单）、`catchphrases`（口头禅清单），供续写沿用。

## 还原要求

1. 续写正文的**视角、句长节奏、比喻、环境描写密度**照抄风格指纹中的抽象特征。
2. **沿用风格指纹中的具体抓手清单**（文化符号、道具、绰号、口头禅），而不是自创通用比喻。
3. 每个角色的说话方式、用词、称呼、行事逻辑严格按人物档案复刻；保留其口头禅。
4. 沿用原著的叙述文体（文白夹杂就文白夹杂，口语化就口语化）。
5. **情绪呈现规则**（决定「悲感/衰感」是否到位，最易出错）：

   a. **用事件承载情绪，不用形容词。** 呈现一个人的"衰/悲"，靠**具体发生的事**（被当字母"e"贴屏幕蹲下、体育比不过对方还打不赢、递出去的花被忽略），而不是"他好惨""心里像被撞了一下""千疮百孔的心"这类概括性旁白。读者要亲眼看到事情发生，才信他衰。

   b. **保留冷场，别急着化解。** 原文的难堪常常**没人接茬、冷冰冰地晾着**（"也没人多看一眼""他什么都不是"）。续写时不要立刻用另一个角色的玩笑把尴尬盖过去，否则就丢了那种窒息的静默感。

   c. **文化梗必须咬合角色当下思维，而非作者硬排。** 调用星际/Wall-E/日漫梗，应当是**路明非此刻心里自然浮现的联想**（如看Wall-E想到"小姑娘救她的衰仔"），而不是为了让句子俏皮而硬塞一个无关比喻。

   d. **给结果即收，不追加解释/金句/哲理总结。** 原文写到"他什么都不是"就**停了**，不补一句"他觉得自己像个笑话"或"人生原来如此"。删掉多余的补注与升华，让读者自己尝到那点酸。

   e. **少用静态形容性比喻，多用动作/事件带出状态。** 避免"像根腌过的萝卜""睡得像只死猪"这类**概括人物状态的静态比喻**；原文多用**一件事/一个动作**（"衰了太多年，已经习惯了，于是'哦'了一声"）来呈现，而不是比喻句。

   f. **人物独白宁可笨拙，不要漂亮金句。** 路明非不会用一句通顺的哲理句总结自己的处境，他是**笨拙地用一件件具体的事**去对抗落差。独白应保留那种"说得磕磕绊绊、跳回具体事"的拙感，而非升华成格言。

   g. **玩闹中可以猝然见刀。** 延续原文那种"前一秒纯小孩气、下一秒砸下一句沉重的话"的冷转折，但要用前面足够的铺垫托住，避免钩子显得硬搭。

6. **校验标准**：读者把续写与原文并排读时，不应产生「少了点味道 / 换了套比喻」的错位感。

## 边界

- **不承诺**「100% 复制某位在世作者文风」。
- 表述应改为：**「按照用户提供文本中可观察到的抽象叙事特征进行续写。」**
- 不混入现代网络用语，除非原著本来就有。

## 合规

- 不将模型推断伪装成原作者计划。
- 不声称续写代表原作者。
- 避免不必要地复制大段原文。
